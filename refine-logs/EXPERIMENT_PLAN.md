# 构造感知自回归 GNN 泛化实验计划

**修订时间：2026-08-14**

## 目标

验证候选—约束图上的动态可行性掩码自回归 GNN，能否在不在线调用 MILP、无事后硬解码的条件下，输出资源可行的离散路径—构造计划，并泛化到未见规模、未见 Waxman 参数和未见拓扑族。

## 方法

- 离线教师：两阶段精确 0/1 MILP，先最大化期望完成质量，再最小化完成延迟。
- 学生：候选—约束二部图 GNN，自回归选择候选或 STOP。
- 可行性：每一步在 softmax 前用当前剩余资源精确屏蔽非法候选。
- 监督：MILP 最优解的无序正确动作集合。
- checkpoint：优先选择验证集 pooled throughput ratio，其次比较图平均吞吐、延迟 gap 和损失。
- 在线推理：不调用 LP/MILP，不做阈值解码、计划修复、局部搜索或贪心后处理。

## 数据划分

- 训练：64、96、128 节点的三组 Waxman 分布，共 9 个 episode。
- 验证：160 节点、未见 Waxman 参数，共 2 个 episode。
- 离线测试：192 节点 Waxman 与 128 节点 Barabasi--Albert，共 4 个 episode。
- 所有 episode seed 不重叠；测试拓扑和请求不参与训练或 checkpoint 选择。
- 教师标签必须具有数值零 MILP gap。

## 训练与在线评价

- 训练随机种子：20260821、20260822、20260823。
- 每个模型最多 25 epoch，早停 patience=10。
- 在线模型只按验证集选择。
- 在线 OOD 场景：192 节点 Waxman 20 个新 seed；128 节点 Barabasi--Albert 20 个新 seed。
- 每个 seed 的 GNN 与 Q-CAST 使用完全相同的 EpisodeSpec 和独立同配置 SeQUeNCe 执行器。

## 指标与门槛

- 离线：pooled MILP 吞吐保留率、吞吐最优率、可行率、随机可行基线、训练种子方差。
- 在线：完成请求数为主指标，平均截尾延迟为次指标，决策耗时单独报告。
- 统计：配对 bootstrap 95% CI 与配对随机化检验。
- 硬门槛：非法 GNN 决策、非名义调度违例、物理后端拒绝和完成后校验失败必须为 0。
